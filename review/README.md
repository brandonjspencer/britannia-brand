# Britannia illustration treatment study — not approved production artwork

The brand website has been restored to the approved original raster artwork. The study in this folder is separate from that identity.

The study SVG contains actual editable vector paths and masks, with no embedded image. Its name and tagline are typeset Libre Caslon Text (outlined from the font), not traced lettering. The existing script B and the previously favored hammers have been retained. The crown, olive tree and tower use an illustrative cleanup study converted to vector contours. They change details from the approved artwork and require explicit visual review; they must not be represented as exact matches or approved production masters.

The included raster cleanup study was generated with the built-in image generation tool using the supplied approved reference as an edit target. It is an intermediate style study, not vector artwork. It is retained here for transparent provenance.

## Cleanup prompt
Use case: precise-object-edit / logo-brand. Create a meticulous high-resolution cleanup master of ONLY THE CENTRAL FOUR-QUADRANT SHIELD in the supplied approved Britannia seal. Treat the supplied image as the edit target and exact visual authority. Remove the outer circular name and fleur-de-lis and tagline, and isolate the shield centered on a completely plain white background with generous margins. The four quadrant illustrations and shield must preserve the reference design, proportions, relative sizes and placement extremely closely. Top left: the same graceful calligraphic B with the same small detailed old-world gold crown. Top right: the same crossed antique carpenters' hammers, with strong fine engraved planes. Bottom left: the SAME dense, full round-canopy olive tree with many small pointed oval leaves, elegant natural curved branches, substantial rooted trunk and flared roots. It must not become sparse, symmetrical, spindly or a modern stock tree icon. Bottom right: the SAME stone castle tower with the same four crenellations, narrow arched doorway, same staggered masonry courses, strong illustrated mortar lines and subtle engraved chisel detail. Match its craftsmanship and line weight to the hammers. Keep the lower-right tower cropped naturally by the shield border as in the reference. Style: exceptionally clean professionally drawn heritage vector illustration, confident smooth contours with intentional hand-crafted curved shapes and precise fine engraved detailing. Preserve the approved traditional heraldic look, not a redesign. No pixel stair steps, no melted or lumpy leaf or crown contours, no holes from raster texture, no rough carbon-copy artifacts. Use only flat deep green #1B2B23, antique gold #886F47 and white for negative spaces; no paper grain, shadows, gradients, mockup, bevel, distress texture or color noise. The shield border consists of the same elegant green/gold/green nested outlines, continuous and well-proportioned. Render large and sharp so the illustrative contours can be converted to editable vector paths. The image must look like a careful professional redraw of THIS approved heraldic shield, not a reinterpretation or a simplified version.
